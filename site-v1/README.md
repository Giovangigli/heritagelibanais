# Site public v1

`dist/` is a snapshot of the current local public-site output from `heritage-libanais-site` at integration time. It is retained for reference and rollback; it is not the Studio deployment source.

The current WordPress theme source is in `../wordpress-theme/heritage-libanais/`. The private Studio v2 source is in `../apps/online/` and `../apps/cards/`. WordPress and each Studio app deploy separately.

The original local `heritage-libanais-site` directory remains untouched and contains additional design, preparation, and review material that is not part of this repository snapshot.
